# 絆記録会 エントリーシステム

陸上競技の記録会「絆記録会」のエントリー受付システムです。
トップページ（`/`）はアスリートキャリアセンターの「大会開催」ページで、年度ごとの開催予定と、
各大会の大会要項・プログラム・リザルト・写真館・取材申込みへのリンク、エントリーへの入口を表示します。
内容は管理画面の大会登録・編集で更新します（資料はPDFのアップロードかURL）。

- 最初の画面で、エントリー方法が2通りあることを案内する
  1. **Webでエントリー**：「団体申し込み」か「個人申し込み」を選ぶ（下記）
  2. **エクセル（エントリーシート）を添付**：今までのエントリーシートを添付するだけ。アカウント登録・ログインは不要。
     読み込んだ内容（選手・申込み種目・申請タイム・自己ベスト・PRしたい一言）を確認して、そのまま支払いへ進む。
     読み込んだ申込はWebエントリーと同じデータになり、運営の申込一覧・Excel出力にそのまま入る（元のシートも管理画面から取り出せる）
- 団体：代表者が団体登録（初期登録）をし、所属選手を一度だけ登録する。
  これまで提出していたエントリーシート（.xlsx）をそのままアップロードして、まとめて登録することもできる。
  次回からは **団体名＋パスワード** で団体の申込データを開く（団体名は全角・半角、大文字・小文字、空白の違いを区別せず、重複登録はできない）
- 個人：選手本人の情報ごと登録し、メールアドレス＋パスワードでログインする
- 大会ごとに、選手一覧から出場する選手にチェックを入れ、申込み種目・申請タイム・PRしたい一言（任意）を入力する。自己ベストは申込では聞かない
  - 「前回と同じ内容で申し込む」ボタンで、前回の選手・種目・申請タイムをまとめて入れられる
  - 申請タイムは数字だけでも入力できる（1430 → 14'30、40530 → 4'05"30）
  - 複数の選手にチェックを入れて、同じ種目を一括で設定できる
  - 前回同じ種目に出た選手は、種目を選ぶと前回の申請タイムが入る
- 年度初めに「年度更新」で選手の学年を1つ上げる（卒業学年の選手は対象外にするか進学して続けるかを選ぶ）
- 参加費を自動計算し、支払い方法を選んで決済する
  - クレジットカード：Stripe Checkout（Link を有効にすると2回目以降はカード入力を省ける）
  - コンビニ払い：KOMOJU（払込番号を発行し、コンビニで支払うと入金済みになる。期限切れは自動で取消）。
    締切後の入金も受け付けるが、画面とメールで「できる限り申込日の当日中に」支払うよう案内する
- 決済サービスからの入金通知（Webhook）でエントリーを「入金済み」にし、入金完了メールを自動送信
- 入金が完了したら **領収書（PDF）を自動発行** して入金完了メールに添付する（宛名は申込時に指定、空なら団体名）。
  エントリー詳細・状態確認ページからいつでもダウンロードでき、運営は管理画面で宛名を直せる。
  発行者は株式会社アスリートキャリアセンター（登録番号 T6012301013979）で、適格請求書として税率10%の対象額と消費税額を載せる
- 運営は管理画面で大会・種目（定員・男女）を設定する。参加料は大会要項どおり区分別
  （中学生・高校生大学生・一般実業団、1種目ごと）に設定でき、選手の種別から自動で決まる。
  コンビニ払いの手数料（`KOMOJU_FEE`）は申込者負担として合計に足す
- **大会資料（PDF）**：タイムテーブル・組編成（スタートリスト）・大会プログラム・リザルトはPDFを貼る運用。
  エントリーデータをExcelで出力（種目ごとのシートは申請タイム順・同タイムは自己ベスト順、部門つき）→ 微調整 → PDFを作って
  管理画面の「大会資料（PDF）」に貼ると、大会開催ページにボタンが出る。リザルトは写真判定機から出力したPDFを貼る。
  ボタンには「暫定版」「0628更新」などのメモを添えられる
- **取材・撮影のお申込み**：大会開催ページのボタンからフォームで受け付け、確認メールを送る。運営は管理画面で一覧を見る
- 運営の「申込一覧」で、全団体・個人の申込を種目ごとに **申請タイム順（同タイムは自己ベスト順）** で確認する。
  同じ申請タイムの選手は黄色で表示し、運営がリクマガなどで調べた自己ベストをその場で入力できる。
  団体・状態で絞り込み、エントリーシートと同じ列の Excel で出力できる

## 技術構成

| 役割 | 使うもの |
|---|---|
| アプリ | PHP 8.3 / Laravel 13（画面は Blade。Node.js のビルドは不要） |
| データベース | MySQL（Xserver）／開発時は SQLite |
| 決済 | カード：Stripe Checkout ＋ Webhook／コンビニ：KOMOJU ＋ Webhook |
| メール | Xserver の SMTP |
| 公開 | GitHub Actions で Xserver に自動アップロード（[手順](docs/deploy-xserver.md)） |

## 画面の流れ

1. `/entry` でエントリー方法（Web／エクセル添付）を選ぶ。Webの場合は団体／個人を選ぶ
   - 団体：`/team/login`（団体名＋パスワード）、はじめては `/team/register` で団体登録 → `/athletes` 選手登録
   - 個人：`/individual/login`（メール＋パスワード）、はじめては `/individual/register`
2. トップページで大会を選ぶ → `/meets/{id}/entry` 選手にチェック・種目を選ぶ → 確認画面
3. 「支払いへ進む」→ Stripe の決済ページ → 支払い完了で `/entries/{id}/complete`
4. Webhook（`/stripe/webhook`・`/komoju/webhook`）で入金済みにし、代表者へメール（運営に BCC 可）
5. 決済ページで「戻る」を押すとエントリーは取り消され、選んだ内容は入力欄に戻る

定員は「入金済み＋決済待ち」で数えます。決済ページは60分で期限切れになり、Stripe の
`checkout.session.expired` 通知で決済待ちのエントリーは自動で取り消されて枠が空きます。

## 開発環境での起動

```sh
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed   # 動作確認用のデータを入れる
php artisan serve
```

- 運営：団体申し込みで 団体名 `絆記録会 運営` / `password`
- 団体：団体申し込みで 団体名 `絆AC` / `password`
- 個人：個人申し込みで `solo@example.com` / `password`

Stripe のテスト用キーを `.env` に入れると、決済まで試せます。Webhook をローカルで受けるには
[Stripe CLI](https://docs.stripe.com/stripe-cli) の `stripe listen --forward-to localhost:8000/stripe/webhook` を使います
（キーがなくても、Webhook 以外の画面とテストは動きます）。
